# PerlOps Brand Identity

Official visual identity, brand assets, and design guidelines for the PerlOps ecosystem.

## Brand Overview

| Attribute | Value |
|---|---|
| Brand name | PerlOps |
| Official tagline | Automate. Secure. Modernize. |
| Brand Kit version | 2.1 |
| Identity | Modern, minimal, technical |
| Organization | [github.com/perlops](https://github.com/perlops) |

## Brand Philosophy

The PerlOps visual identity represents the intersection of proven technology and modern engineering.

The camel represents the Perl ecosystem, while the integrated terminal symbol represents automation, infrastructure operations, and software engineering.

## Official Color Palette

| Color | HEX | RGB |
|---|---|---|
| Deep Navy | `#0B1F33` | 11, 31, 51 |
| PerlOps Teal | `#00BFA5` | 0, 191, 165 |
| Pure White | `#FFFFFF` | 255, 255, 255 |

## Brand Assets

This repository will provide:

- Master vector logos
- Horizontal and vertical logo variants
- Light and dark theme variants
- Transparent background assets
- Monochrome logos
- Social media assets
- Application icons and favicons
- Brand guidelines
- Versioned brand kit releases

## Brand Usage Guidelines

### Recommended

- Use official brand assets.
- Maintain the original logo proportions.
- Preserve the official color palette.
- Ensure sufficient contrast and clear space.
- Use the appropriate light or dark variant.

### Not Recommended

- Distorting or stretching the logo.
- Modifying the camel silhouette.
- Altering the integrated terminal symbol.
- Changing the official colors.
- Adding shadows, gradients, or decorative effects.
- Modifying the official tagline.

## Official Tagline

**Automate. Secure. Modernize.**

The tagline must remain unchanged across all official PerlOps materials.

## Brand Kit Releases

Complete brand asset packages will be distributed through GitHub Releases.

| Version | Description |
|---|---|
| v2.1 | Approved visual identity and corrected tagline colors |

## Brand Usage and Permissions

PerlOps brand assets are maintained separately from the source code of PerlOps software projects.

Software licenses do not automatically grant permission to use PerlOps branding.

Do not use the PerlOps identity in a manner that implies endorsement, affiliation, or official partnership without authorization.

Additional brand usage terms may be introduced in future revisions.

## Contributing

Suggestions and improvements to brand documentation are welcome through GitHub Issues.

Changes to the official visual identity require approval from the project maintainers.
